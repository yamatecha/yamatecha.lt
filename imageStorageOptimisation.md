Best Free Solutions for 100-200 Images
1. GitHub/GitLab Pages (Completely Free)
Storage: Up to 1GB free
Bandwidth: 100GB/month (GitHub), unlimited (GitLab)
Perfect for: Static sites like yours
Setup: Store images in public/ folder, deploy with GitHub Actions
2. Vercel/Netlify (Free Tier)
Image optimization: Built-in, free
CDN: Global distribution
Bandwidth: 100GB/month
Easy: Connect your Git repo, auto-deploy
3. Free Cloudinary Alternative
Cloudinary free tier: 25GB storage/bandwidth (likely enough)
Imgix free tier: Similar limits
No credit card required for free tiers
4. Self-Hosted with Optimization
bash
# Install image optimizer
npm install sharp imagemin
Store locally: In public/images/
Optimize during build: Convert to WebP, resize
Free: Completely, just your hosting cost
